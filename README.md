G Uwimpuhwe, R Drikvandi, SA Blozis (2026). "TestREnlme: An R Package for Testing Random Effects in Nonlinear Mixed-Effects Models". Journal of Statistical Software. Under Review.
The package can be installed using the following two commands in R:

library(remotes)

install_github("germaine86/TestREnlme")
