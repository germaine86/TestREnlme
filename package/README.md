# TestREnlme

This repository contains two complementary components:

## 1. `paper-reproducibility/`

This folder contains the original research code used in the data analyses and numerical studies reported in:

> Uwimpuhwe, G., Drikvandi, R., and Blozis, S. A. (2026). *Testing Random Effects in Nonlinear Mixed-Effects Models*. *Statistics in Medicine*.

The code is provided to facilitate exact reproduction of the published results.

## 2. `package/`

This folder contains the actively maintained **TestREnlme** R package. The package includes improved computational efficiency, enhanced numerical stability, updated documentation, and ongoing development beyond the original research implementation.

For routine analyses, users are encouraged to use the package version. For exact replication of the published results, users should use the code contained in `paper-reproducibility/`.
